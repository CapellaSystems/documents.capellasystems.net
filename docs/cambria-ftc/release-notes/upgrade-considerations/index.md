## Things to Consider When Upgrading

### System Compatibility

Confirm that all FTC and Cluster machines meet the newer version’s supported operating-system, processor, memory, and hardware requirements.

### Floating License Server Compatibility

Existing licenses will continue to work. If the Floating License Server is also upgraded, confirm that its host operating system is supported by the new server version.

### API and Security Changes

Update integrations to use HTTPS and verify the required ports.
