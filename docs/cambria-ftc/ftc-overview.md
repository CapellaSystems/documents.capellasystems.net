# Cambria FTC

Cambria FTC is Capella Systems' file-based transcoding solution for professional media workflows.

Use this documentation to learn about Cambria FTC, install and configure the software, review release information, integrate with the API, and follow workflow-specific tutorials.

## Common Workflows

Cambria FTC supports workflows including file-based transcoding, Watch Folder automation, video and audio processing, HDR and color-space conversion, subtitles and captions, adaptive streaming, and network or cloud storage.
