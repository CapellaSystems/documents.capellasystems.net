Cambria FTC is Capella Systems' file-based transcoding solution for professional media workflows.

Use this documentation to learn about Cambria FTC, install and configure the product, review release information, integrate with the API, and follow common workflow tutorials.

Cambria FTC documentation includes guidance for workflows such as:

- File-based transcoding
- Watch Folder automation
- Video and audio processing
- Resolution and frame-rate conversion
- Aspect-ratio conversion
- HDR and color-space conversion
- Subtitle and caption processing
- Adaptive streaming output
- Cloud and network storage workflows
- Cambria Cluster deployments
